# Contributing

- Run `make check` (lint and unit tests) before opening a PR. `make e2e` writes to a `remind-test` list in your Reminders.
- Keep the interface small. Open an issue before adding a command or flag.
- If commands, flags, or output change, update `remind help`, `README.md`, `README.ko.md`, and `skills/remind/SKILL.md` together.
- Commit messages: `<type>: <description>` in English.
- Agents follow `AGENTS.md`.
